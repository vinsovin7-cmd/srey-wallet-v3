# AlphaQubit Quantum Research & Live Ecosystem (Srey Wallet)

An integrated Web3 ecosystem and multi-feature decentralized finance & communication platform featuring:

- **Srey Wallet**: High-speed multi-chain wallet (TON & Solana) with Tonviewer and Solscan.io deep integration, live balance tracking, and smart contract payout distribution.
- **TON Ad Revenue Aggregator**: Revenue distribution engine, automated payouts, and AdsGram rewarded video Telegram Mini App (TMA).
- **Franz Multi-Messenger Core Wrapper**: Multi-service dashboard with isolated sandboxing and owner bypass.
- **Sreymara Queen Conversational AI**: Voice & text conversational agent with real-time speech and context awareness.
- **Master Admin Palace**: Complete telemetry, real-time analytics, and system monitoring.

## Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons
- **Blockchain**: TON Connect UI, TonWeb, Solana Web3.js
- **PWA**: Offline caching, installable progressive web application

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
